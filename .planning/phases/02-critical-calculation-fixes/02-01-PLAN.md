<objective>
Ispraviti kritične bagove u gustinama materijala (CuZn15, CuZn20, CuZn30) i konvertovati Material tip sa String na Kotlin enum sa type-safe density propertijom. Ovo eliminiše string manipulation ranjivosti i obezbeđuje tačne proračune za sve materijale.

Output: Material enum u Models.kt sa ispravnim gustinama, ažuriran Calculator.kt koji koristi enum, ažurirani UI fajlovi koji prosleđuju Material enum, uklonjena MATERIAL_DENSITIES mapa, ažurirani ProGuard rules.
</objective>

**Models.kt — Dodati Material enum:**

Dodati `Material` enum class iznad postojećih data klasa u Models.kt. Enum mora imati:
- `density: Int` property u konstruktoru
- 6 vrednosti sa ISPRAVNIM gustinama:

```kotlin
fun parseMaterial(raw: String): Material {
    val trimmed = raw.trim()
    if (trimmed.isEmpty()) {
        throw IllegalArgumentException("Molimo odaberite materijal iz liste.")
    }
    return Material.fromDisplayName(trimmed)
        ?: throw IllegalArgumentException("Nepoznat materijal. Koristite Cu, CuZn10, CuZn15, CuZn20, CuZn30 ili CuZn37.")
}
```

4. Potpuno zameniti `getDensity(material: String): Int` sa:

NE MENJATI calculateOuterDiameter() — Double precision je adekvatna za ±10% toleranciju (research potvrđuje). Samo verifikovati da redosled operacija ostaje isti.
